## 1. 探測基本概念

### 什麼是探測？

探測就是用一根**探測棒**（Touch Probe）去碰觸工件，當探測棒接觸到工件表面的瞬間，機台會記錄下那個位置的座標。透過這個方式可以：

- 找到工件的**邊界位置**（X/Y 座標）
- 找到工件的**中心點**
- 量測工件的**寬度/直徑**
- 量測表面的**角度**
- 自動設定**工件座標原點**（WCS G54~G59）

### 探測的物理原理

```
          主軸
          ┃
     ┌────╂────┐
     │  探測棒  │
     │    │    │
     │    │    │
     │    ●    │  ← 探針尖端（紅色球形）
     │         │
     └─────────┘
          ↓ 慢慢移動
    ┌──────────────┐
    │    工件      │  ← 碰到的瞬間，機台記錄座標
    └──────────────┘
```

**碰觸的瞬間**，後端發送的 G-Code 是 **G38.2**（探測指令），LinuxCNC 會自動在碰觸時停止移動並記錄座標。

### 探測棒半徑補正

因為探測棒的尖端是有直徑的球體，碰到的點並不是球心位置。系統會自動讀取刀具表中探測棒的直徑，算出半徑，然後補正到正確位置：

```
    ● 球心（機台記錄的位置）
   /|\
  / | \
 /  |  \  ← 半徑 R
/   |   \
────●────  ← 實際接觸點（補正後的位置）
    │
════════════ 工件表面
```

## 3. 左側參數欄位完整說明

### WCS 選擇區

| 欄位 | 用途 |
|------|------|
| **G54 ~ G59.3** | 選擇探測結果要寫入哪組工件座標系。按下對應按鈕（9 組可選）。探測成功後，系統自動用 G10 L20 把探到的座標寫進這組 WCS |
| **PROBE POSITION ONLY** | 勾選時：探測完只顯示結果，**不寫入 WCS**。用於確認或測試時使用 |

### 探測參數（10 個輸入欄位）

```
┌──────────────────┬──────────────────┐
│ Probe Tool #   1 │ Slow Probe F 0.3 │
│ Traverse F   300 │ Fast Probe F 1.0 │
│ XY Max Dist   20 │ XY Clearance   5 │
│ Z Max Dist    20 │ Z Clearance    5 │
│ Extra Depth    2 │ Offset Width   0 │
└──────────────────┴──────────────────┘
```

| # | 參數名稱 | 預設值 | 單位 | 白話說明 |
|---|---------|--------|------|---------|
| 1 | **Probe Tool #** | 1 | — | 探測棒的刀號。系統會自動 G43 載入這把刀的長度補正，並讀取直徑做半徑補正 |
| 2 | **Slow Probe Feed** | 0.3 | mm/min | 慢速探測速率（目前版本尚未啟用兩段式探測，保留未來用） |
| 3 | **Traverse Feed** | 300 | mm/min | 探測前移動到準備位置的速度（快速定位）。送到後端的 JSON key: `TraverseSpeed` |
| 4 | **Fast Probe Feed** | 1.0 | mm/min | 實際探測時的進給速率（G38.2 的 F 值）。越慢越精準。送到後端的 JSON key: `SearchSpeed` |
| 5 | **XY Max Distance** | 20 | mm | XY 方向最大搜尋距離。探測棒最多走這麼遠，如果還沒碰到就判定失敗 |
| 6 | **XY Clearance** | 5 | mm | XY 方向的安全退刀距離。探測碰觸後退回多遠 |
| 7 | **Z Max Distance** | 20 | mm | Z 方向最大搜尋距離 |
| 8 | **Z Clearance** | 5 | mm | Z 方向的安全高度。探測前先下降到「目前位置 - Z Clearance - Extra Depth」 |
| 9 | **Extra Probe Depth** | 2 | mm | 額外下探深度。確保探測棒的接觸點低於工件表面 |
| 10 | **Offset Width** | 0 | mm | Step-off 寬度（對齊 ProbotBuild 用，部分探測類型使用） |

### 參數如何影響探測動作（圖解）

```
探測前的定位（以探測 X+ 方向為例）：

    目前位置（手動移到的大概位置）
        ↓
        ●
        │
        │ ← Z Clearance + Extra Depth（先下降）
        ↓
        ●──────────────────→  ← XY Max Distance（G38.2 搜尋）
                              如果在這範圍內碰到工件 → 成功
                              如果走完都沒碰到 → 失敗

        碰到後：
        ●←─── XY Clearance（退回安全距離）
        │
        │ ← Z Clearance + Extra Depth（升回原高度）
        ↑
        ●（回到出發位置）
```

### Boss/Pocket 專用參數（Boss & Pocket 分頁底部）

| 參數 | 用途 |
|------|------|
| **DIAM** (`BossPocketDiam`) | 凸台/凹穴的大約直徑。系統用這個計算要往外移多遠再探回來 |
| **X** (`BossPocketOffsetX`) | 凸台/凹穴的中心相對於目前位置的 X 偏移 |
| **Y** (`BossPocketOffsetY`) | 凸台/凹穴的中心相對於目前位置的 Y 偏移 |

### Ridge/Valley 專用參數（Ridge & Valley 分頁底部）

| 參數 | 用途 |
|------|------|
| **X** (`RidgeValleyOffsetX`) | 脊/谷的中心相對於目前位置的 X 偏移 |
| **Y** (`RidgeValleyOffsetY`) | 脊/谷的中心相對於目前位置的 Y 偏移 |

### Edge Angle 專用參數（Edge Angle 分頁底部）

| 參數 | 用途 |
|------|------|
| **EDGE WIDTH** (`EdgeWidthInput`) | 兩次探測之間的間距（mm）。兩個探測點越遠，角度計算越精確。若為 0，預設用 3×XY Clearance |

## 4. 結果顯示區（3×4 格）說明

探測完成後，結果會顯示在左側面板的下方：

```
┌────────────────┬────────────────┬────────────────┐
│  X- PROBE      │  X+ PROBE      │  X WIDTH       │
│  (ResultX)     │  (ResultXOffset)│  (ResultWidthX)│
├────────────────┼────────────────┼────────────────┤
│  Y- PROBE      │  Y+ PROBE      │  Y WIDTH       │
│  (ResultY)     │  (ResultYOffset)│  (ResultWidthY)│
├────────────────┼────────────────┼────────────────┤
│  Z- PROBE      │  DIAM ∅        │  X CENTER      │
│  (ResultZ)     │  (ResultEdgeW) │  (ResultXCenter)│
├────────────────┼────────────────┼────────────────┤
│  EDGE Δ        │  EDGE ∠        │  Y CENTER      │
│  (ResultEdgeΔ) │  (ResultAngle) │  (ResultYCenter)│
└────────────────┴────────────────┴────────────────┘
```

### 每格的意義

| 欄位 | 意義 | 哪些探測類型會填入 |
|------|------|------------------|
| **X- PROBE** | X 方向負側（或第一側）的探測座標 | Edge W、Outside/Inside 角落、Boss/Pocket/Ridge/Valley |
| **X+ PROBE** | X 方向正側（或第二側）的探測座標 | 多側探測（Boss XY、Pocket XY 等） |
| **X WIDTH** | X 方向的寬度（X+ 和 X- 的距離） | Boss/Pocket/Ridge/Valley 的 X 或 XY 探測 |
| **Y- PROBE** | Y 方向負側的探測座標 | Edge S、角落、Boss/Pocket/Ridge/Valley |
| **Y+ PROBE** | Y 方向正側的探測座標 | 多側探測 |
| **Y WIDTH** | Y 方向的寬度 | Boss/Pocket/Ridge/Valley 的 Y 或 XY 探測 |
| **Z- PROBE** | Z 探測座標 | 所有探測類型都會回傳 Z |
| **DIAM ∅** | 直徑（或邊寬）| Boss/Pocket XY、Edge Angle |
| **X CENTER** | X 方向的中心座標 | Center、Boss/Pocket XY |
| **EDGE Δ** | 邊緣差量 | Edge Angle |
| **EDGE ∠** | 角度（度） | Edge Angle |
| **Y CENTER** | Y 方向的中心座標 | Center、Boss/Pocket XY |

### 4 個清除按鈕

| 按鈕 | 功能 |
|------|------|
| **UPDATE PARAMS** | 儲存目前參數到 probe_settings.json |
| **CLEAR ALL DATA** | 全部 12 格結果歸零 |
| **CLEAR X DATA** | 只清除 X 相關（X-、X+、X WIDTH） |
| **CLEAR Y DATA** | 只清除 Y 相關（Y-、Y+、Y WIDTH） |

## 5. 探測類型詳解

### 5.1 Outside — 外側邊探測

**用途：** 從工件的**外面**去碰工件的邊界，找到邊的位置。

#### 9 宮格按鈕說明

```
┌──────────┬──────────┬──────────┐
│    NW    │    N     │    NE    │
│ 外角 NW  │  北邊 Y- │ 外角 NE  │
│ 量 X+,Y- │  量 Y    │ 量 X-,Y- │
├──────────┼──────────┼──────────┤
│    W     │  CENTER  │    E     │
│  西邊 X+ │ 中心4邊  │  東邊 X- │
│  量 X    │  量 XY   │  量 X    │
├──────────┼──────────┼──────────┤
│    SW    │    S     │    SE    │
│ 外角 SW  │  南邊 Y+ │ 外角 SE  │
│ 量 X+,Y+ │  量 Y    │ 量 X-,Y+ │
└──────────┴──────────┴──────────┘
```

**箭頭方向 = 探測棒移動方向（從外面靠近工件）**

#### 單邊（N/S/E/W）— 量一個軸

```
範例：按 W（探測西邊）

     探測棒 →  ───────→  █████
                          █████  ← 工件
                          █████

1. 探測棒先往下降（Z Clearance + Extra Depth）
2. 往 X+ 方向移動（G38.2），碰到工件西邊
3. 記錄 X 座標（+ 半徑補正）
4. 退回 XY Clearance
5. Z 升回原位

結果：ResultX 填入碰到的 X 座標
     ResultZ 填入碰到時的 Z 座標
```

#### 角落（NW/NE/SW/SE）— 量兩個軸

```
範例：按 NW（探測外角 NW）

     探測棒
        ↓
        → ───→ █████████████
                █████████████ ← 工件
        ↓       █████████████
        ───↓──→ █████████████

1. 先做一次「W」方向探測（量 X）→ 回到原位
2. 再做一次「N」方向探測（量 Y）→ 回到原位
3. 兩次的結果合併 → 得到角落的 (X, Y) 座標

結果：ResultX = 第一次探測的 X
     ResultY = 第二次探測的 Y
     ResultZ = 第一次探測的 Z
```

#### CENTER — 量四邊取中心

```
1. 先探 W → 量 X+
2. 回到原位 → 探 E → 量 X-
3. 回到原位 → 探 S → 量 Y+
4. 回到原位 → 探 N → 量 Y-
5. 計算中心 = (X+ + X-) / 2,  (Y+ + Y-) / 2
6. 計算寬度 = |X+ - X-|,  |Y+ - Y-|

結果：ResultXCenter = X 中心
     ResultYCenter = Y 中心
     ResultWidthX = X 方向寬度
     ResultWidthY = Y 方向寬度
```

#### 使用的左側參數

| 參數 | 是否使用 | 用途 |
|------|---------|------|
| Probe Tool # | ✅ | G43 補正 + 直徑讀取 |
| Fast Probe F | ✅ | G38.2 的 F 值 |
| Traverse F | ✅ | 定位移動速度 |
| XY Max Dist | ✅ | 搜尋極限距離 |
| XY Clearance | ✅ | 碰觸後退回距離 |
| Z Max Dist | ❌ | 不使用（Edge 不探 Z 方向） |
| Z Clearance | ✅ | 先下降多少 |
| Extra Depth | ✅ | 額外下探深度 |
| Slow Probe F | ❌ | 保留（未來兩段式） |
| Offset Width | ❌ | 不使用 |

### 5.2 Inside — 內側邊探測

**用途：** 從工件的**裡面**（孔/凹槽/腔體）去碰內壁，找到內壁位置。

#### 9 宮格按鈕（方向跟 Outside 相反）

```
┌──────────┬──────────┬──────────┐
│    NW    │    N     │    NE    │
│ 內角 NW  │  北壁    │ 內角 NE  │
│量 X-→,Y+↓│量 Y+↓壁 │量 X+←,Y+↓│
├──────────┼──────────┼──────────┤
│    W     │  CENTER  │    E     │
│  西壁←   │ 中心4壁  │  東壁→   │
│量 X-←壁  │  量 XY   │量 X+→壁  │
├──────────┼──────────┼──────────┤
│    SW    │    S     │    SE    │
│ 內角 SW  │  南壁    │ 內角 SE  │
│量 X-→,Y-↑│量 Y-↑壁 │量 X+←,Y-↑│
└──────────┴──────────┴──────────┘
```

**跟 Outside 的差別：**
- Outside：探測棒在外面，往工件靠近
- Inside：探測棒在裡面，往內壁靠近
- 後端自動反轉方向（`inside_edge` → 反轉為相反方向）

#### 典型使用情境

```
        ┌───────────────────┐
        │                   │
        │   ● ← 探測棒     │  ← 工件的孔/腔體
        │   在裡面          │
        │                   │
        └───────────────────┘

按 E → 探測棒往右移動碰觸東壁
按 CENTER → 四壁都碰，算出中心和寬度
```

#### 使用的參數

與 Outside 完全相同。

### 5.3 Boss & Pocket — 凸台/凹穴

**用途：**
- **Boss（凸台）：** 量一個凸起的圓柱或方塊的中心和直徑。探測棒從**外面**繞到各邊探測
- **Pocket（凹穴）：** 量一個凹陷的孔/槽的中心和寬度。探測棒在**裡面**探各壁

#### 6 個按鈕

```
┌──────────┬──────────┬──────────┐
│  BOSS X  │  BOSS Y  │ BOSS XY  │  ← 從外面探凸台
│  量X兩側  │  量Y兩側  │  量XY四側 │
├──────────┼──────────┼──────────┤
│ POCKET X │ POCKET Y │POCKET XY │  ← 從裡面探凹穴
│  量X兩壁  │  量Y兩壁  │  量XY四壁 │
└──────────┴──────────┴──────────┘
```

#### Boss 的探測流程（以 Boss X 為例）

```
    目前位置（在凸台上方中心附近）
         ●
         │
    1. 往 X+ 移動 (直徑/2 + XY Clearance) → 移到凸台外面
         │                    ●
    2. Z 下降                 │
                              ●
    3. G38.2 往 X- 方向探測 ← 碰到凸台 X+ 邊
                         ●════█
    4. 退回 → 升 Z → 回到原位
         ●
    5. 往 X- 方向重複一次 → 碰到凸台 X- 邊
    6. 回到原位

    結果：
    - X CENTER = (X+ 邊 + X- 邊) / 2
    - X WIDTH  = |X+ 邊 - X- 邊|（即直徑）
```

#### Pocket 的探測流程（以 Pocket XY 為例）

```
    目前位置（在凹穴裡面中心附近）
         ●

    1. 從目前位置往 X+ 方向探測 → 碰到東壁
    2. 回到原位 → 往 X- 方向探測 → 碰到西壁
    3. 回到原位 → 往 Y+ 方向探測 → 碰到南壁
    4. 回到原位 → 往 Y- 方向探測 → 碰到北壁
    5. 回到原位

    結果：
    - X CENTER = (東壁 + 西壁) / 2
    - Y CENTER = (南壁 + 北壁) / 2
    - X WIDTH  = |東壁 - 西壁|
    - Y WIDTH  = |南壁 - 北壁|
```

#### 使用的左側參數

| 參數 | Boss 使用 | Pocket 使用 | 用途 |
|------|----------|------------|------|
| 通用 10 個參數 | ✅ 同 Outside | ✅ 同 Inside | — |
| **DIAM** | ✅ | ❌ | Boss：控制往外移多遠（直徑/2 + 安全距離） |
| **X offset** | ✅ | ✅ | 中心偏移量（如果你不在正中心） |
| **Y offset** | ✅ | ✅ | 中心偏移量 |

### 5.4 Ridge & Valley — 脊/谷

**用途：**
- **Ridge（脊）：** 量一條凸起的長條（如肋板）。等同 Boss，但通常只量一個方向
- **Valley（谷）：** 量一條凹槽。等同 Pocket，但通常只量一個方向

#### 6 個按鈕

```
┌──────────┬──────────┬──────────┐
│ RIDGE X  │ RIDGE Y  │ RIDGE XY │  ← 從外面探凸條（同 Boss）
├──────────┼──────────┼──────────┤
│ VALLEY X │ VALLEY Y │VALLEY XY │  ← 從裡面探凹槽（同 Pocket）
└──────────┴──────────┴──────────┘
```

**後端邏輯：**
- Ridge → 呼叫 `_probe_boss()` （跟 Boss 完全一樣）
- Valley → 呼叫 `_probe_center()` （跟 Pocket 完全一樣）

#### 使用的左側參數

| 參數 | 用途 |
|------|------|
| 通用 10 個參數 | 同上 |
| **X offset** (Ridge/Valley 專用) | 中心偏移量。注意：用的是 `RidgeValleyOffsetX`，跟 Boss/Pocket 的 `BossPocketOffsetX` 是**分開的**兩組 |
| **Y offset** (Ridge/Valley 專用) | 同上 |

### 5.5 Edge Angle — 邊角度

**用途：** 量測工件邊緣的傾斜角度。在同一條邊上做**兩次探測**，從兩個碰觸點的座標差算出角度。

#### 原理圖

```
    探測點 1            探測點 2
        ●                   ●
        │                   │
        ↓                   ↓
   ═════╗              ═════╗
         ╲                   ╲  ← 斜邊（有角度）
          ╲                   ╲
           ╲                   ╲
            ╲══════════════════╲════

    兩點之間的距離 = EDGE WIDTH
    角度 = atan2(Y差, X差) 轉成度數
```

#### 9 宮格按鈕

```
┌──────────┬──────────┬──────────┐
│ ANGLE NW │ ANGLE N  │ ANGLE NE │
│ 北邊左起  │ 北邊中央  │ 北邊右起  │
├──────────┼──────────┼──────────┤
│ ANGLE W  │  CENTER  │ ANGLE E  │
│ 西邊     │ 4邊參考   │ 東邊     │
├──────────┼──────────┼──────────┤
│ ANGLE SW │ ANGLE S  │ ANGLE SE │
│ 南邊左起  │ 南邊中央  │ 南邊右起  │
└──────────┴──────────┴──────────┘
```

**各方向的探測邏輯：**

| 按鈕 | 探測哪條邊 | 探測方向 | 兩點偏移方向 |
|------|----------|---------|------------|
| N | 北邊（上邊） | Y-（往下碰） | X 方向偏移 |
| S | 南邊（下邊） | Y+（往上碰） | X 方向偏移 |
| E | 東邊（右邊） | X-（往左碰） | Y 方向偏移 |
| W | 西邊（左邊） | X+（往右碰） | Y 方向偏移 |
| NW | 北邊，從左開始 | Y- | X+ 方向偏移 |
| NE | 北邊，從右開始 | Y- | X- 方向偏移 |
| SW | 南邊，從左開始 | Y+ | X+ 方向偏移 |
| SE | 南邊，從右開始 | Y+ | X- 方向偏移 |
| CENTER | 4 邊參考 | 四邊探測 | 回傳 angle=0 |

#### 探測流程

```
1. 在目前位置做第一次探測（碰到邊的第一點）
2. 回到原位
3. 沿著邊的方向移動 EDGE WIDTH 距離
4. 做第二次探測（碰到邊的第二點）
5. 回到原位

角度計算：
  - 如果探的是 N/S 邊（沿 X 移動）：
    angle = atan2(第二點Y - 第一點Y, 第二點X - 第一點X)
  - 如果探的是 E/W 邊（沿 Y 移動）：
    angle = atan2(第二點X - 第一點X, 第二點Y - 第一點Y)
```

#### 結果欄位

| 結果 | 意義 |
|------|------|
| **EDGE ∠** (ResultAngle) | 計算出的角度（度） |
| **EDGE Δ / DIAM** (ResultEdgeWidth) | 兩個碰觸點之間沿邊的距離 |
| **X/Y** | 兩點的中點座標 |

#### SET ROTATION WCO 按鈕

在 Edge Angle 分頁底部有一個額外按鈕 **SET ROTATION WCO**，按下後會：
```
G10 L2 P{WCS 編號} R{角度}
```
把量到的角度寫入目前選取的 WCS 的旋轉值，讓後續加工自動補正工件的傾斜。

#### 使用的左側參數

| 參數 | 用途 |
|------|------|
| 通用 10 個參數 | 同上 |
| **EDGE WIDTH** | 兩次探測之間的間距。越大，角度計算越準確。如果設 0，預設用 3 × XY Clearance |

### 5.6 Calibrate — 校正

**用途：** 校正探測棒本身的尺寸偏差。用一個已知尺寸的環規或方塊，實際量測後跟已知值比較，算出補正值。

#### 按鈕組

**環規校正（已知直徑的圓環/圓柱）：**

| 按鈕 | 動作 |
|------|------|
| **Ring Inside** | 把探測棒放在環規裡面 → 探 4 壁（等同 Pocket XY） |
| **Ring Outside** | 把探測棒放在圓柱外面 → 探 4 側（等同 Boss XY） |

**方塊校正（已知寬度的方塊）：**

| 按鈕 | 動作 |
|------|------|
| **Square Inside** | 在方塊內腔探 4 壁 |
| **Square Outside** | 在方塊外面探 4 側 |

**誤差計算：**

| 按鈕 | 功能 |
|------|------|
| **Cal XY Avg Error** | 用 X 和 Y 寬度的平均誤差做校正 |
| **Cal X Error** | 只用 X 方向的誤差 |
| **Cal Y Error** | 只用 Y 方向的誤差 |
| **Cal Reset** | 清除所有校正值歸零 |

#### 校正參數

| 參數 | 用途 |
|------|------|
| **Probe Calibration Offset** | 校正偏移量（自動計算結果） |
| **Calibration Diameter** | 環規的已知直徑 |
| **Calibration Width X / Y** | 方塊的已知 X/Y 寬度 |

> 注意：校正值**不會**持久化到 JSON，每次開機都需要重新校正。

### 5.8 Tool Setter — 對刀器

**用途：** 用固定在機台上的對刀器自動量測刀具長度。

#### 操作流程

```
1. 先用 SET TOOL SETTER POS 記錄對刀器的 XYZ 位置
   （手動移動到對刀器正上方，按下記錄）
2. 按 PROBE SPINDLE ZERO → 主軸空載下探 Z，碰到對刀器
   → 記錄主軸零點（無刀具時的基準高度）
3. 之後每次換刀後，在刀具表頁面按 ELECTRONIC TOOL SETTER
   → 自動移到對刀器位置 → 下探 Z → 碰到對刀器
   → 用（碰觸位置 - 主軸零點）算出刀具長度
```

#### Tool Setter 參數（右側面板）

| 參數 | 用途 |
|------|------|
| **Spindle Zero (mm)** | 主軸空載碰到對刀器的 Z 座標（基準值） |
| **Fast Probe Speed** | 快速探測速率 |
| **Slow Probe Speed** | 慢速探測速率 |
| **Traverse Speed** | 定位移動速度 |
| **Z Max Travel** | Z 方向最大搜尋距離 |
| **XY Max Travel** | XY 方向最大搜尋距離 |
| **Retract Distance** | 碰觸後退回距離 |
| **Breakage Tolerance** | 破損容許值（量到的值偏差太大 = 刀可能斷了） |
| **Custom Param 1/2** | 自訂參數（保留） |

#### Tool Setter 位置/方向

| 參數 | 用途 |
|------|------|
| **X / Y / Z** | 對刀器在機台上的固定位置座標 |
| **Tool Diam Probe** | 量到的刀具直徑 |
| **Tool Diam Offset** | 刀具直徑補正值 |
| **方向 (▲▼◄►)** | 刀具偏移方向（BACK/FRONT/LEFT/RIGHT） |

## 6. 探測流程（後端 G-Code 層面）

### 完整的單次探測動作（_probe_edge）

```
前端發送 POST /v2/probe/run
  { probe_type: "edge", direction: "W", search_speed: 1.0, ... }

後端 probe.py 收到後：
  ┌─ 安全檢查 ─────────────────────────────────────────┐
  │ 1. 確認 LinuxCNC NML 連線正常                       │
  │ 2. 確認不在急停狀態（STATE_ESTOP → 拒絕）            │
  │ 3. 確認機台通電（STATE_ON）                         │
  │ 4. 切到 MDI 模式                                   │
  │ 5. G43 H{tool} 載入探測棒長度補正                   │
  │ 6. 讀取探測棒直徑 → 算出 probe_radius               │
  └─────────────────────────────────────────────────────┘

  ┌─ 探測動作 ─────────────────────────────────────────┐
  │ 7. G91 G0 Z{-extra_depth-z_clearance}              │
  │    （相對模式，Z 下降到探測面以下）                   │
  │                                                     │
  │ 8. 安全確認：probe_val 是否 LOW                     │
  │    （如果已經是 HIGH = 探測棒已觸發 → 異常，中止）    │
  │                                                     │
  │ 9. G91 G38.2 X{max_xy_dist} F{search_speed}       │
  │    （相對模式，往 X+ 方向探測）                      │
  │    → 碰到工件 → LinuxCNC 自動停止                    │
  │                                                     │
  │ 10. 讀取 probe_get_result()                        │
  │     → { tripped: true, x: 123.456, y: 0, z: -7.0 } │
  │                                                     │
  │ 11. 半徑補正：x += probe_radius（探測棒球心→表面）   │
  │                                                     │
  │ 12. G91 G0 X{-xy_clearance}（退回安全距離）         │
  │ 13. G91 G0 Z{extra_depth+z_clearance}（Z 升回原位） │
  │ 14. G90（回到絕對模式）                             │
  └─────────────────────────────────────────────────────┘

  ┌─ WCS 自動寫入 ─────────────────────────────────────┐
  │ 15. 如果有選 WCS 且不是 PROBE POSITION ONLY：       │
  │     G10 L20 P{1~9} X{result.x} Y{result.y} Z{...} │
  │     （自動把探測結果寫入選定的工件座標系）             │
  └─────────────────────────────────────────────────────┘

  ┌─ 回傳結果 ─────────────────────────────────────────┐
  │ { Tripped: true, X: 123.456, Y: 0, Z: -7.0 }      │
  └─────────────────────────────────────────────────────┘
```

## 8. 安全注意事項

| 項目 | 說明 |
|------|------|
| **急停檢查** | 每次探測前後端都會確認不在急停狀態 |
| **通電檢查** | 機台必須在 STATE_ON 狀態 |
| **探測棒預觸發** | 開始前檢查 probe_val 是否 LOW（如果已經 HIGH = 可能已碰到東西，異常中止） |
| **超時** | G38.2 預設 60 秒超時，沒碰到就放棄 |
| **Probe HttpClient** | 前端 timeout = 120 秒（因為有些多次探測需要較長時間） |
| **ESC 中斷** | 探測中隨時可按 ESC 或按 STOP 按鈕中斷 |
| **參數持久化** | 探測參數存在 probe_settings.json，不會因為關閉軟體而遺失 |
| **WCS 寫入** | 勾選 PROBE POSITION ONLY 可以避免意外覆蓋座標系 |
| **半徑補正** | 自動從刀具表讀取，無需手動輸入。但前提是刀具表中探測棒的直徑要正確 |

## 9. 常見問題

### Q: 探測失敗顯示「探測未觸發」？
**A:** 探測棒在 XY Max Distance 範圍內沒碰到工件。可能原因：
- 起始位置離工件太遠 → 加大 XY Max Distance
- 起始位置不對 → 手動移近一點再試
- 探測方向選錯 → 確認按鈕方向

### Q: 探測結果不準確？
**A:** 可能原因：
- Fast Probe Feed 太快 → 降到 0.5 以下
- 探測棒直徑沒設好 → 檢查刀具表
- 需要校正 → 用 Calibrate 分頁校正

### Q: Boss 探測失敗？
**A:** DIAM 參數要設定正確。系統用 `DIAM/2 + XY Clearance` 計算往外移多遠。如果 DIAM 太小，探測棒可能還在凸台上方就開始探測。

### Q: 什麼時候用 PROBE POSITION ONLY？
**A:**
- 第一次試探：先看看結果對不對 → 勾選
- 確認 OK 後：取消勾選 → 重新探測 → 自動寫入 WCS
- 只想量尺寸不想動座標 → 勾選

### Q: 目前有兩段式探測嗎？
**A:** **沒有**。目前所有探測都是單次 G38.2（Fast Probe Feed）。Slow Probe Feed 參數已預留，但後端尚未實作兩段式（快探 → 退回 → 慢探）。這是未來優化項目。
