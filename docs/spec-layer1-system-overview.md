# 第一層：系統總覽（給完全不懂程式的人看）

> 本文件用最白話的方式說明這套 CNC 控制器是什麼、能做什麼、怎麼操作。
> 不需要任何程式背景就能看懂。

---

## 1. 這套系統在做什麼？

這是一套 **CNC 工具機的控制軟體**，就像手機的 App 控制家電一樣：

```
┌──────────────┐        網路線         ┌──────────────┐        馬達線         ┌──────────┐
│  觸控螢幕     │  ─────────────────→  │  Linux 電腦   │  ─────────────────→  │  CNC 機台 │
│ （Windows）   │  ←─────────────────  │ （機台主控）   │  ←─────────────────  │ （加工件） │
│              │     操作指令/狀態回報   │              │     馬達控制/感測回報  │          │
└──────────────┘                       └──────────────┘                       └──────────┘
   你摸得到的畫面                         藏在機台裡的電腦                        實際在動的機器
```

**白話說：**
- **觸控螢幕**（Windows 電腦）：操作員用手指點按鈕、看數據的地方
- **Linux 電腦**（藏在機台裡）：真正控制馬達轉多快、移多遠的大腦
- **CNC 機台**：實際在切削金屬的機器（有 X/Y/Z 軸，有些還有旋轉的 A/B/C 軸）

觸控螢幕跟 Linux 電腦之間靠**網路線**溝通（就像瀏覽器開網頁一樣）。

## 3. 有哪些頁面？（主要功能）

用左側導航按鈕切換，共有這些頁面：

### 🔹 MAIN（主頁面）
- 看到目前機台的即時座標（X/Y/Z 位置）
- 底部有加工控制按鈕（開始/暫停/停止）
- 右邊有手動移動按鈕（JOG）

### 🔹 MONITOR（程式監控）
- 載入 G-Code 加工程式（像開一個文字檔）
- 可以編輯程式、上傳到機台
- 右邊有 3D 預覽，看刀具會走什麼路線
- 下方可輸入 MDI（手動輸入單行指令）

### 🔹 FILE（檔案管理）
- 看機台上有哪些加工程式
- 選一個程式 → 預覽內容 → 載入到機台
- 可以刪除、重新命名程式

### 🔹 OFFSETS（座標偏移）
- 設定工件座標系（G54 ~ G59）
- 意思是：告訴機台「工件的原點在哪裡」
- 可以歸零、清除、儲存座標

### 🔹 TOOL TABLE（刀具表）
- 管理所有刀具的資料（長度、直徑、偏移量）
- TOOL LIFE 分頁：追蹤每把刀用了多久、換了幾次

### 🔹 ATC（自動換刀）
- MANUAL 模式：手動控制刀盤旋轉、夾刀、鬆刀
- AUTOMATIC 模式：按一個按鈕就自動換刀
- 中間有刀盤的視覺化轉盤圖

### 🔹 PROBING（探測）
- 用探測棒量測工件的位置和尺寸
- 8 種探測類型：
  - 外側邊（Outside）：量工件的外邊界
  - 內側邊（Inside）：量孔的內壁
  - 凸台（Boss）：量圓柱體的外緣
  - 凹槽（Ridge/Valley）：量溝槽
  - 角度（Edge Angle）：量傾斜面的角度
  - 校正（Calibrate）：校正探測棒本身
  - 說明（Help）：圖文說明怎麼用
  - 對刀器（Tool Setter）：自動量刀具長度

### 🔹 MACRO（巨集變數）
- 讀寫機台內部的數字變數（#1 ~ #5999）
- 這些變數控制機台的各種內部參數

### 🔹 HISTORY（歷史記錄）
- LOG 分頁：看所有操作記錄和錯誤訊息
- STATS 分頁：看哪些錯誤最常出現（Top 10 排行）

### 🔹 SETTINGS（設定）
共 13 個子分頁：
- **HARDWARE**：掃描機台上接了哪些設備（EtherCAT）
- **AXIS MAPPING**：設定哪顆馬達對應哪個軸
- **AXIS PARAMETER**：設定每個軸的速度、加速度
- **IO MONITOR**：即時監看輸入/輸出信號（像看開關狀態）
- **MACHINE CONFIG**：設定 IO 對應（哪個信號控制什麼功能）
- **SPINDLE**：主軸馬達設定（轉速、剛性攻牙）
- **ATC BASIC/AXIS/IO**：刀庫的基本設定、軸設定、IO 設定
- **MACRO VARIABLES**：巨集變數（同上面的 MACRO 頁面）
- **BACKUP**：備份/還原所有設定
- **MAINTENANCE**：維護保養提醒（例如：每 500 小時換油）

## 4. 常用操作流程

### 開機流程
```
1. 開啟軟體
2. 軟體自動連接 Linux 電腦（畫面出現「Connected」）
3. 軟體自動驗證硬體（檢查馬達、感測器是否正常）
4. 按 F1（POWER 開）→ 機台通電
5. 按 REF ALL → 所有軸回原點（歸零）
6. 載入 G-Code 程式 → 按 CYCLE START 開始加工
```

### 換刀流程（自動）
```
1. 切到 ATC 頁面
2. 在 AUTOMATIC 區域輸入刀號（例如 T3）
3. 按 M6 G43 → 機台自動：
   - 主軸上升到安全高度
   - 刀盤伸出、旋轉到正確位置
   - 鬆開舊刀 → 裝上新刀 → 夾緊
   - 刀盤收回
```

### 探測流程（量工件外側）
```
1. 先把探測棒裝到主軸上
2. 手動移到工件旁邊（大概位置就好）
3. 切到 PROBING 頁面 → 選 Outside 分頁
4. 輸入參數（探測距離、速度）
5. 按對應方向的按鈕（例如 X+）
6. 探測棒會慢慢移動直到碰到工件
7. 結果自動顯示（量到的 X/Y/Z 座標）
```

### 緊急停止
```
- 按畫面上的 E-STOP 按鈕
- 或按鍵盤 F2
- 或按鍵盤 ESC（全機停止 + 清除警報）
```

## 5. 名詞對照表

| 英文術語 | 中文說明 | 白話解釋 |
|---------|---------|---------|
| CNC | 電腦數值控制 | 用電腦控制機器切削金屬 |
| G-Code | G 碼程式 | 告訴機器「移到哪裡、轉多快、切多深」的指令檔 |
| DRO | 數位讀出器 | 畫面上顯示 X/Y/Z 座標的那一排數字 |
| JOG | 手動移動 | 用按鈕一點一點移動機台軸 |
| MDI | 手動資料輸入 | 直接打一行 G-Code 指令讓機台執行 |
| Feedrate | 進給速率 | 刀具移動的速度（mm/分鐘） |
| Spindle | 主軸 | 夾住刀具旋轉的那根軸 |
| RPM | 每分鐘轉速 | 主軸一分鐘轉幾圈 |
| Override | 倍率調整 | 臨時加減速，例如 50% = 原本速度的一半 |
| ATC | 自動換刀裝置 | 機器自動把刀具換掉的機構 |
| Carousel | 刀盤/刀庫 | 圓形的刀具架，上面插著好幾把刀 |
| Drawbar | 拉桿 | 夾住/鬆開刀具的機構 |
| Clamp | 夾刀 | 把刀具鎖緊在主軸上 |
| Unclamp | 鬆刀 | 把刀具從主軸鬆開 |
| Probing | 探測 | 用感測棒觸碰工件來量測位置 |
| Tool Setter | 對刀器 | 自動量測刀具長度的裝置 |
| WCS | 工件座標系 | 以工件為基準的座標（G54~G59） |
| G54-G59 | 座標偏移 | 6 組不同的工件座標設定 |
| Offsets | 偏移值 | 機台座標和工件座標之間的差值 |
| Home | 原點復歸 | 讓軸回到機器的零點位置 |
| E-Stop | 緊急停止 | 一按就立刻停掉所有動作 |
| Feed Hold | 進給暫停 | 暫停加工（刀具停住，主軸繼續轉） |
| Cycle Start | 循環啟動 | 按下去開始執行加工程式 |
| Single Block | 單節執行 | 一次只執行一行 G-Code（除錯用） |
| Block Delete | 跳過刪除 | 跳過 G-Code 裡標記 / 的那一行 |
| M01 Break | 選擇性停止 | 程式遇到 M01 會暫停（操作員決定要不要繼續） |
| Flood | 切削液(滿) | 大量噴切削液冷卻 |
| Mist | 切削液(霧) | 噴霧狀切削液 |
| EtherCAT | 工業乙太網 | 連接馬達和感測器的高速通訊線路 |
| HAL | 硬體抽象層 | Linux 電腦裡管理硬體信號的系統 |
| INI | 設定檔 | 機台的設定參數檔案（像 Windows 的 .ini） |
| NGC | 巨集程式 | 機台內部的子程式（用 O-word 語法） |
| Macro Variable | 巨集變數 | 機台內部的可讀寫數字（#1~#5999） |
| Servo | 伺服馬達 | 精密控制位置和速度的馬達 |
| Encoder | 編碼器 | 偵測馬達轉了多少的感測器 |
| DTG | 剩餘距離 | 目前指令還要走多遠 |
| Rigid Tapping | 剛性攻牙 | 主軸跟 Z 軸同步運動來攻螺紋 |
| M19 | 主軸定向 | 讓主軸停在固定角度（換刀用） |
| Backup | 備份 | 把所有設定存一份副本 |
| Restore | 還原 | 用之前的備份把設定救回來 |
| Resume | 斷電續切 | 停電後從上次停的地方繼續加工 |

## 6. 安全注意事項（非常重要）

| 情境 | 系統怎麼保護你 |
|------|--------------|
| 操作員按錯按鈕 | 每個動作都有雙重檢查，機台不在對的狀態就不會動 |
| 網路斷線 | 連續 3 次通訊失敗才判斷斷線，畫面顯示紅色警告 |
| 程式寫錯座標 | 可以用 Feed Hold 暫停、用 STOP 緊急停止 |
| 突然停電 | 系統每 5 秒自動存檔，開機會問你要不要從上次的位置繼續 |
| 忘記回原點就操作 | 系統會檢查 Homed 狀態，沒回原點的軸不能 JOG |
| 急停按鈕 | 獨立通道（不受其他操作影響），2 秒內一定送達 |

## 7. 使用者權限

| 角色 | 能做什麼 |
|------|---------|
| Operator（操作員） | 基本加工操作、看座標、換刀 |
| Engineer（工程師） | 以上 + 修改參數、設定座標 |
| Admin（管理員） | 以上 + 備份還原、維護設定 |
| Developer（開發者） | 全部功能（含硬體設定） |

登入方式：點右上角使用者名稱 → 輸入密碼。
