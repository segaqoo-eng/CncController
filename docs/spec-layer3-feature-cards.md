## 01. 即時狀態輪詢

```
┌─────────────────────────────────────────────────────┐
│ 功能名稱：即時狀態輪詢（Status Polling）               │
├─────────────────────────────────────────────────────┤
│ 操作方式：                                           │
│   自動運作，不需要手動操作。                            │
│   軟體啟動後每 50 毫秒跟後端要一次最新狀態，            │
│   畫面上所有數字（座標、轉速、狀態）都靠這個機制刷新。    │
├─────────────────────────────────────────────────────┤
│ 前端檔案：                                           │
│   - 邏輯：ViewModels/MainViewModel.Polling.cs        │
│   - 通訊：Services/MachineControlService.cs          │
│         → GetStatusAsync()                          │
│   - 資料：Models/MachineStatus.cs（~200 個屬性）      │
│   - 資料：Models/StatusModels.cs（JSON DTO）          │
├─────────────────────────────────────────────────────┤
│ 後端檔案：                                           │
│   - Server/routes/status.py                         │
│   - Server/shared.py（快取機制）                      │
├─────────────────────────────────────────────────────┤
│ API：                                               │
│   GET /v2/status → 回傳即時狀態 JSON                  │
│   GET /v2/errors → 回傳錯誤訊息佇列（≤20 筆）         │
├─────────────────────────────────────────────────────┤
│ 資料流：                                             │
│   後端背景 Thread 1（20ms）→ 快取座標/狀態             │
│   後端背景 Thread 2（1s）→ 快取 IO/編碼器             │
│   前端 Timer（50ms）→ GET /v2/status                 │
│   → 回傳快取（<1ms）→ UpdateMachineData()             │
│   → MachineStatus 屬性更新 → UI 自動刷新              │
│   低頻分頻（每 20 tick ≈ 1s）→ PollErrors()          │
├─────────────────────────────────────────────────────┤
│ 關鍵參數：                                           │
│   - 輪詢間隔：50ms（DispatcherTimer）                 │
│   - 後端快取高頻：20ms                               │
│   - 後端快取低頻：1s                                  │
│   - 斷線判定：連續 3 次失敗                            │
│   - Polling HttpClient timeout：3 秒                 │
├─────────────────────────────────────────────────────┤
│ 安全注意事項：                                        │
│   - 不可把輪詢間隔改太短（< 20ms），會灌爆後端          │
│   - 不可把 timeout 改太長，會導致畫面卡頓               │
│   - 斷線判定次數不可改成 1，網路偶爾抖動會誤判          │
└─────────────────────────────────────────────────────┘
```

## 02. DRO 座標顯示

```
┌─────────────────────────────────────────────────────┐
│ 功能名稱：DRO 座標顯示                               │
├─────────────────────────────────────────────────────┤
│ 操作方式：                                           │
│   畫面底部的座標顯示區，5 欄：                         │
│   ZERO | WORK (G5X) | MACHINE | DTG | REF          │
│   - ZERO 按鈕：將該軸的工件座標歸零                    │
│   - WORK：目前工件座標（會隨 WCS 改變）               │
│   - MACHINE：機台絕對座標                            │
│   - DTG：目前指令剩餘距離                             │
│   - REF 按鈕：該軸回原點（紅色=未歸零，綠色=已歸零）    │
│   - ZERO ALL：全軸歸零                               │
│   - REF ALL：全軸回原點                              │
├─────────────────────────────────────────────────────┤
│ 前端檔案：                                           │
│   - 畫面：Views/Components/DroDisplay.xaml           │
│   - 邏輯：ViewModels/MainViewModel.Dro.cs           │
├─────────────────────────────────────────────────────┤
│ 後端：                                               │
│   - GET /v2/status（Position/Homed 欄位）            │
│   - POST /v2/machine/home（原點復歸）                 │
│   - POST /v2/mdi（G10 L20 歸零指令）                 │
├─────────────────────────────────────────────────────┤
│ 顯示邏輯：                                           │
│   - 3 軸模式：只顯示 X/Y/Z                           │
│   - 4/5/6 軸模式：額外顯示 A/B/C（依 MachineType）   │
│   - 軸可見性綁定：IsAxisAEnabled / B / C              │
├─────────────────────────────────────────────────────┤
│ 安全注意事項：                                        │
│   - REF（Home）操作會讓軸實際移動，確保周圍淨空        │
│   - ZERO 只是改座標數值，不會讓軸移動                  │
│   - REF ALL 會同時移動所有軸                          │
└─────────────────────────────────────────────────────┘
```

## 03. JOG 手動移動

```
┌─────────────────────────────────────────────────────┐
│ 功能名稱：JOG 手動移動                               │
├─────────────────────────────────────────────────────┤
│ 操作方式：                                           │
│   右側 JOG 面板，按住方向按鈕讓軸移動：                │
│   - Z+/Z-（上下）                                    │
│   - X+/X-/Y+/Y-（十字方向盤）                        │
│   - A+/A-/B+/B-/C+/C-（旋轉軸，如果有的話）          │
│                                                     │
│   4 種 JOG 模式：                                    │
│   - JOG（連續）：按住一直動，放開就停                  │
│   - 0.1 / 0.01 / 0.001：按一下走固定距離（寸動）      │
│                                                     │
│   JOG 速度：用滑桿調整（0~100%）                      │
├─────────────────────────────────────────────────────┤
│ 前端檔案：                                           │
│   - 畫面：Views/Layouts/JogPanel.xaml                │
│   - 速度設定：Views/Components/JogConfig.xaml         │
│   - 邏輯：ViewModels/MainViewModel.Jog.cs            │
├─────────────────────────────────────────────────────┤
│ 後端：                                               │
│   - POST /v2/motion/jog                             │
│     body: { axis: 0~5, speed: float, distance: float }│
├─────────────────────────────────────────────────────┤
│ 操作機制：                                           │
│   - 連續 JOG：按下觸發 JogStart，放開觸發 JogStop    │
│   - 寸動 JOG：按下觸發一次，走 distance 後自動停      │
│   - 使用 PreviewMouseDown/Up 事件（觸控兼容）         │
├─────────────────────────────────────────────────────┤
│ 安全注意事項：                                        │
│   - 雙重守衛：VM CanExecuteMotion() + Service        │
│     ValidateAction() 都通過才能動                     │
│   - 未回原點的軸不可 JOG（除非 Joint 模式）           │
│   - 急停狀態下 JOG 完全禁用                           │
│   - 連續 JOG 的 MouseLeave 也會觸發 Stop（防止         │
│     手指滑出按鈕後軸繼續動）                           │
└─────────────────────────────────────────────────────┘
```

## 04. 加工循環控制

```
┌─────────────────────────────────────────────────────┐
│ 功能名稱：加工循環控制（Cycle Control）                │
├─────────────────────────────────────────────────────┤
│ 操作方式：                                           │
│   底部 D_1 區域的 10 個按鈕（5×2 格）：               │
│                                                     │
│   CYCLE START  │  STOP         │  RELOAD PGM        │
│   FEED HOLD    │  CLEAR PGM    │                    │
│   SINGLE BLOCK │  BLOCK DELETE │  FLOOD             │
│   MIST         │  M01 BREAK    │                    │
│                                                     │
│   - CYCLE START：開始執行已載入的 G-Code               │
│     （加工中變綠色）                                   │
│   - FEED HOLD：暫停進給（暫停中變橘色）                │
│   - STOP：完全停止加工                                │
│   - SINGLE BLOCK：每按一次只執行一行（除錯用）          │
│   - BLOCK DELETE：跳過以 / 開頭的行                   │
│   - M01 BREAK：遇到 M01 指令會暫停                   │
│   - FLOOD/MIST：切削液控制（按一下開，再按關）          │
│   - RELOAD PGM：重新載入程式                          │
│   - CLEAR PGM：清除已載入的程式                       │
├─────────────────────────────────────────────────────┤
│ 前端檔案：                                           │
│   - 畫面：Views/Components/CycleControl.xaml         │
│   - 邏輯：ViewModels/MainViewModel.CycleControl.cs   │
├─────────────────────────────────────────────────────┤
│ 後端 API：                                           │
│   POST /v2/program/run      → 開始執行               │
│   POST /v2/program/pause    → 暫停（Feed Hold）      │
│   POST /v2/program/resume   → 繼續                   │
│   POST /v2/program/stop     → 完全停止（abort）       │
│   POST /v2/program/step     → 單節執行               │
│   POST /v2/program/block_delete → 切換 Block Delete  │
│   POST /v2/program/optional_stop → 切換 M01 Break    │
├─────────────────────────────────────────────────────┤
│ 按鈕動態色彩（DataTrigger）：                         │
│   - CYCLE START：InterpState=RUNNING + AUTO → 綠     │
│   - FEED HOLD：InterpState=PAUSED → 橘              │
│   - POWER：IsPower=True → 綠                        │
│   - E-STOP：IsEstop=False → 紅（正常狀態紅=提醒）     │
│   - FLOOD/MIST/SINGLE BLOCK：開啟時 → 藍             │
├─────────────────────────────────────────────────────┤
│ 安全注意事項：                                        │
│   - STOP 會發送 abort()，立即停止所有軸運動            │
│   - Feed Hold 只暫停進給，主軸繼續轉                   │
│   - 確認在 AUTO 模式下才能 CYCLE START                │
└─────────────────────────────────────────────────────┘
```

## 06. 電源與急停

```
┌─────────────────────────────────────────────────────┐
│ 功能名稱：電源與急停（Power / E-Stop）                │
├─────────────────────────────────────────────────────┤
│ 操作方式：                                           │

│   - E-STOP 按鈕（F2）：緊急停止                      │

├─────────────────────────────────────────────────────┤
│ 前端檔案：                                           │
│   - 畫面：Views/Components/CycleControl.xaml         │
│   - 邏輯：ViewModels/MainViewModel.Safety.cs         │
│   - 快捷鍵：MainWindow.xaml（InputBindings）          │
├─────────────────────────────────────────────────────┤
│ 後端 API：                                           │
│   POST /v2/machine/reset  → 電源切換（智慧判斷狀態）   │
│   POST /v2/machine/estop  → 緊急停止                 │
├─────────────────────────────────────────────────────┤
│ 狀態機：                                             │
│   ESTOP → reset → ESTOP_RESET → reset → ON          │
│   ON → estop → ESTOP                                │
│   ON → reset → OFF                                  │
├─────────────────────────────────────────────────────┤
│ 安全注意事項：                                        │
│   - E-Stop 使用獨立 HttpClient（2s timeout）          │
│   - 不受其他 HTTP 請求堵塞影響                        │
│   - 急停後會「樂觀更新」畫面（不等後端回覆就先改狀態）   │
│   - EmergencyAbort (ESC) 會同時：                     │
│     1. 發送 abort（停止所有軸）                       │
│     2. 取消進行中的 JOG                              │
│     3. 清除活動警報                                   │
└─────────────────────────────────────────────────────┘
```
